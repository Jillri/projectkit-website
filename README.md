# ProjectKit — GitHub Pages landing page

A fully static landing page. No external scripts, frameworks, or image APIs.

## Deploy
1. Create a public GitHub repository.
2. Upload `index.html`, `styles.css`, and the entire `assets/` directory to the repository root.
3. Go to **Settings → Pages → Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Visit `https://YOUR-USERNAME.github.io/YOUR-REPO/`.

## Assets
- `assets/app-icon.png`: original icon provided by the app developer.
- `assets/project-overview.webp`, `dashboard.webp`, `profile.webp`: optimized conversions of the three original iPhone screenshots supplied by the developer. No generated or simulated app interfaces are used.

## Before publishing
- Add your own verified support and privacy policy links in the footer when available.
- The Mac/iPad section intentionally uses the app icon rather than invented platform screenshots. Add real Mac/iPad screenshots if you have them.
- If you change the public URL, consider adding a canonical URL and absolute Open Graph image URL.
